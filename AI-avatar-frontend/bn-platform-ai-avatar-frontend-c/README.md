# Project Name

prototype of client application where you can upload video and
send it to application server

## 🔐 Authentication (Mock)

> ⚠️ This project currently uses a **mock login** in `lib/userLogin.ts` because the backend authentication API is not yet available.

- The `userLogIn` function returns a static mock user.
- You can change this behavior later to call the real API once it's ready.
- For production, make sure to remove or disable mock logic.

## 🚀 Features

 - Login / Logout 

## 🖥️ Tech Stack

- React / Next.js
- Tailwind CSS

## 📦 Installation

install dependencies.

- npm install

- you need to set environment in .env.example and change it to .env.local
